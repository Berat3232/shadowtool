# 👤 ShadowTool
ShadowTool, siber güvenlik araştırmacıları için geliştirilmiş bir otomasyon aracıdır. Nmap taramaları, otomatik paket kurulumu ve yerel dizinleri Cloudflare üzerinden internete açma işlemlerini tek bir menüden yapmanızı sağlar.

### 🚀 Özellikler
* **Hızlı Kurulum:** Gereken tüm paketleri otomatik indirir.
* **Ağ Taraması:** Nmap ile hedef sistem analizleri yapar.
* **Web Tünelleme:** Port açmadan yerel sitenizi dış dünyaya açar.

### 🛠️ Kullanım
1. `chmod +x shadowtool.sh`
2. `./shadowtool.sh`


# 👤 ShadowTool
ShadowTool is a security automation script. It simplifies Nmap scans, package installations, and exposes local directories to the internet via Cloudflare Tunnels through an interactive menu.

### 🚀 Features
* **Auto Setup:** Installs all required dependencies.
* **Network Scan:** Integrated Nmap analysis.
* **Tunneling:** Exposes local server to the web without port forwarding.

### 🛠️ Usage
1. `chmod +x shadowtool.sh`
2. `./shadowtool.sh`
