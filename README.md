👤 ShadowTool
ShadowTool, siber güvenlik araştırmacıları için geliştirilmiş, yerel dizinleri port açmadan Cloudflare tünelleri üzerinden internete açan hızlı bir otomasyon aracıdır.

🚀 Kullanım
Dosyaları İndirin: Proje klasöründeki script dosyasını bilgisayarınıza alın.

Yetki Verin: Terminalden chmod +x shadowtool.sh komutunu çalıştırın.

Başlatın: ./shadowtool.sh yazarak menüye ulaşın.

Özellikler: Tek tıkla paket kurulumu, otomatik Python sunucusu ve güvenli tünelleme.
